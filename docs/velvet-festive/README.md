# Festive storefront and adult entry confirmation

Uploaded to the unpublished Shopify theme **Velvet Noir - Festive**, ID 167729856569, on ivh0uz-ej.myshopify.com.

Preview: https://ivh0uz-ej.myshopify.com/?preview_theme_id=167729856569

The Christmas homepage uses burgundy, evergreen and gold, with CSS ornaments and editable seasonal text. Existing curated product imagery is retained. Theme settings contain independent Festive season and Age confirmation switches; disabling the seasonal switch restores the original hero.

The 18+ dialog blocks browsing until accepted, remembers acceptance for the current browser tab, keeps keyboard focus inside, and provides an under-18 exit. JavaScript-disabled browsers receive a blocking explanation. The theme editor skips the dialog; use the storefront preview to test it.

Validation: all nine changed files passed Shopify Liquid validation, with inherited warnings in the original theme. The local browser harness passed 30 checks at desktop and mobile widths, including focus, Escape, acceptance, navigation, decline, blocked storage and disabled JavaScript. Screenshots and check results are included. Browser checks used a local rendering fixture, rather than an authenticated Shopify storefront.

This directory contains the nine changed theme files, not a complete standalone theme. Publish this draft from Shopify admin > Online Store > Themes when ready. The connector does not support theme publishing.
